## 🚀 Projetos em destaque

### DashKommo — Dashboard de CRM

Dashboard para acompanhamento de leads e análise do funil de vendas, integrado à API do Kommo CRM.

**Tecnologias:** TypeScript, Node.js, Express, MySQL e Next.js.

### Automação de contratos

Solução desenvolvida em Python para gerar contratos personalizados a partir de planilhas e templates Word, preparando documentos para assinatura eletrônica.

**Tecnologias:** Python, Excel, Word e integração com serviços de assinatura digital.

### RHumi — Sistema de gestão de recursos humanos

Projeto de desenvolvimento de uma API para um sistema de gestão de recursos humanos, com funcionalidades relacionadas a colaboradores, recrutamento, avaliações e desenvolvimento profissional.

**Tecnologias:** TypeScript, Node.js e PostgreSQL.
